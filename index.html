03 — Decision reliability

Does a decision hold when the options change?

Two tests, combined into one reliability score.

S

Order stability

How often the model keeps its answer across 12 reorderings of the options; 0 is chance, 1 always.

N

Null discrimination

How well the model's “no option is correct” probability flags items whose correct option was removed: 2·AUC − 1; 0 is chance, 1 perfect.

R

Reliability

R = √(S·N), as a percentage.

05 — The benchmark

2,919 tasks in 11 domains

Static questions and web and tool sandboxes, posed through one decision interface.

How the leaderboard is scored

Domains count equally, each on its hardest tier (Math: hard and very hard; untiered domains: all tasks): 1,232 tasks.

06 — Evaluate

Evaluate your model

Any model, through an adapter. Linux x86-64, Python 3.12.

Step 01 · Get the data 
./jev fetch-data --output /path/to/so-arena-data
export SO_ARENA_DATA=/path/to/so-arena-data
./jev verify
./jev setup

verify checks every data file against the release.

Step 02 · Run your model 
export JEV_ENDPOINT=http://localhost:8000
./jev run --adapter adapters:http \
  --model your-model --out /path/to/new-run

--resume continues a run; --limit makes a quick check.

Step 03 · Score 
./jev score --run /path/to/new-run \
  --output /path/to/report.json

The leaderboard score, by domain and tier.

Full instructions: the SO-Arena repository.
