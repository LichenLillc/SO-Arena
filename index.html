02 — Decision reliability

Does a decision hold when the options change?

Two tests, combined into one reliability score R; the charts below show the results.

S

Order stability

Does the model keep its answer when the options are shuffled? Measured over 12 reorderings; 0 is chance, 1 always.

N

Null discrimination

Does it notice when the correct option is missing? Measured by how well its “no option is correct” probability separates such items (2·AUC − 1); 0 is chance, 1 perfect.

R

Reliability

Both at once: R = √(S·N), as a percentage.

04 — The benchmark

2,919 tasks in 11 domains

Static questions and web and tool sandboxes, posed through one decision interface.

How the leaderboard is scored

Domains count equally whatever their size (20 to 200 leaderboard tasks), each on its hardest tier (Math: hard and very hard; untiered domains: all tasks): 1,232 tasks.

05 — Evaluate

Evaluate your model

The jev command evaluates any model through an adapter. Linux x86-64, Python 3.12.

Step 01 · Get the data 
git clone https://github.com/holdrain/SO-Arena && cd SO-Arena
./jev fetch-data --output /path/to/so-arena-data
export SO_ARENA_DATA=/path/to/so-arena-data
./jev verify
./jev setup

verify checks every data file against the release.

Step 02 · Run your model 
export JEV_ENDPOINT=http://localhost:8000
./jev run --adapter adapters:http \
  --model your-model --out /path/to/new-run

Your server answers POST /predict with the decision (an option, yes/no, a grade or option probabilities) and POST /measure with token counts. Web and tool tasks arrive as a series of one-step decisions.

Step 03 · Score 
./jev score --run /path/to/new-run \
  --output /path/to/report.json

The leaderboard score, by domain and tier.

Full instructions: the SO-Arena repository. Data terms: there is no single licence yet; each task keeps its source's terms, listed in the repository's third-party notices.
