How the leaderboard is scored

Domains count equally, each on its hardest tier: 1,232 tasks.

C(m)=100D∑d=1D1|Td|∑i∈Tdci(m)

ci(m) ∈ [0, 1] is model m's credit on task i; Td holds domain d's leaderboard tasks; D = 11.

05 — Evaluate

Evaluate your model

Three commands, any model.

Step 01 · Get the data 
git clone https://github.com/holdrain/SO-Arena && cd SO-Arena
./jev fetch-data --output /path/to/so-arena-data
export SO_ARENA_DATA=/path/to/so-arena-data
./jev verify
./jev setup

Downloads and checks the data.

Step 02 · Run your model 
export JEV_ENDPOINT=http://localhost:8000
./jev run --adapter adapters:http \
  --model your-model --out /path/to/new-run

Point it at your model server.

Step 03 · Score 
./jev score --run /path/to/new-run \
  --output /path/to/report.json

The leaderboard score, by domain and tier.

Full instructions: the SO-Arena repository.
